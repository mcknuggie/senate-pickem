# Senate Pick'em 2026

A 16-bit style pick'em for the 16 most competitive 2026 U.S. Senate races.

- **Polls:** loaded live from [PollResults.org](https://pollresults.org/) (data from The New York Times polls page, CC BY 4.0). Polling averages are calculated in the page.
- **Odds:** loaded live from the public [Polymarket US API](https://docs.polymarket.us/api-reference) (midpoint of best bid and ask).
- If either source can't be reached, the page falls back to a built-in snapshot from Oct 21, 2026.

Single static file (`index.html`), hosted with GitHub Pages. Just a game; for voting information go to [vote.gov](https://vote.gov).
